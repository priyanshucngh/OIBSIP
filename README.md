# Oasis Infobyte Data Science Internship (OIBSIP)

## Overview
This repository contains the completed tasks for the **Oasis Infobyte Data Science Internship**. The projects cover various domains of Data Science, Machine Learning, and Data Analysis using Python.

---

## 📂 Repository Structure & Tasks Summary

### Task 1: Iris Flower Classification
- **Directory:** `DataScience-Task1-IrisFlowerClassification`
- **Objective:** Classify iris flowers into Setosa, Versicolor, and Virginica species using ML models.
- **Key Concepts:** Classification, Exploratory Data Analysis, Model Evaluation.

### Task 2: Unemployment Analysis
- **Directory:** `DataScience-Task2-UnemploymentAnalysis`
- **Objective:** Analyze unemployment rate trends in India across different states and regions, particularly during the COVID-19 pandemic.
- **Key Concepts:** Data Visualization, Time Series Analysis, Data Cleaning.

### Task 3: Car Price Prediction
- **Directory:** `DataScience-Task3-CarPricePrediction`
- **Objective:** Build regression models to accurately predict used car prices based on vehicle attributes.
- **Key Concepts:** Feature Engineering, Regression Algorithms, Model Performance Metrics.

### Task 4: Email Spam Detection
- **Directory:** `DataScience-Task4-EmailSpamDetection`
- **Objective:** Develop a text classification model to distinguish spam messages from ham (legitimate) messages.
- **Key Concepts:** Text Preprocessing, TF-IDF Vectorization, NLP Classification.
