# Car Price Prediction using Machine Learning

## Oasis Infobyte Data Science Internship - Task 3

### Objective

The objective of this project is to predict the selling price of used cars
using machine learning regression techniques.

### Dataset

Vehicle dataset from CarDekho.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### Models Used

1. Linear Regression
2. Random Forest Regressor

### Methodology

1. Data Collection
2. Data Inspection
3. Data Cleaning
4. Exploratory Data Analysis
5. Feature Engineering
6. Categorical Encoding
7. Train-Test Split
8. Model Training
9. Model Evaluation
10. Feature Importance Analysis

### Feature Engineering

- Car Age
- Brand

### Evaluation Metrics

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

### Result

The performance of Linear Regression and Random Forest Regressor was compared
using multiple evaluation metrics. The model with the better overall
performance was selected as the preferred model.

### Conclusion

Machine learning can be used to estimate used car selling prices based on
vehicle characteristics and historical data.
