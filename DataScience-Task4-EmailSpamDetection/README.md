# Email Spam Detection using Machine Learning

## Oasis Infobyte Data Science Internship - Task 4

### Objective

The objective of this project is to classify messages as Spam or Ham using
machine learning and text classification techniques.

### Dataset

SMS Spam Collection Dataset.

### Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Regular Expressions
- Jupyter Notebook

### Machine Learning Models

1. Multinomial Naive Bayes
2. Linear Support Vector Machine

### Methodology

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Text Preprocessing
5. TF-IDF Vectorization
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Model Comparison
10. Prediction on New Messages

### Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- Confusion Matrix

### Result

The two machine learning models were compared using multiple evaluation
metrics. The model with the better overall F1 score was selected as the
preferred model.

### Conclusion

Machine learning and TF-IDF based text representation can be effectively
used to classify messages as spam or ham.
