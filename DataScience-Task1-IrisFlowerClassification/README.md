# Iris Flower Classification using Machine Learning

## Oasis Infobyte Data Science Internship - Task 1

### Objective
The objective of this project is to build a machine learning model to classify iris flowers into three species (Setosa, Versicolor, and Virginica) based on their sepal and petal measurements.

### Dataset
Iris Flower Dataset.

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

### Machine Learning Models
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree Classifier

### Methodology
1. Data Collection
2. Data Inspection
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Feature Scaling
6. Train-Test Split
7. Model Training
8. Model Evaluation
9. Model Comparison

### Evaluation Metrics
- Accuracy Score
- Precision
- Recall
- F1 Score
- Confusion Matrix

### Result
The performance of multiple machine learning algorithms was evaluated. The model achieving the highest accuracy and overall F1 score was selected for final predictions.

### Conclusion
Supervised machine learning algorithms can accurately classify iris species based on physical measurements of sepals and petals.
