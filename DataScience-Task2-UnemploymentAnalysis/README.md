# Unemployment Analysis using Python

## Oasis Infobyte Data Science Internship - Task 2

### Objective
The objective of this project is to analyze unemployment rate data, identify key trends, and understand the economic impact of events like the COVID-19 pandemic using data visualization techniques.

### Dataset
Unemployment in India Dataset (containing unemployment rates, area type, and temporal data across different states).

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook

### Methodology
1. Data Collection
2. Data Inspection & Missing Value Treatment
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Time Series Trend Analysis
6. State-wise & Region-wise Analysis
7. Pre-COVID vs Post-COVID Impact Analysis

### Key Insights
- Visualized the spike in unemployment rate across various Indian states during the lockdown period.
- Compared urban vs rural unemployment trends over time.
- Highlighted the most impacted regions during the economic slowdown.

### Conclusion
Data visualization techniques effectively reveal regional disparities and severe economic disruptions, helping policy analysts understand workforce impacts during crises.
